# Sales Profitability Optimization

A data analytics and business intelligence project focused on analyzing sales performance, profitability, discounts, products, regions, and sales channels using Python, PostgreSQL, SQL, and Power BI.

## Project Overview

The objective of this project is to transform sales transaction data into meaningful business insights that can support better pricing, product, regional, and channel-level decisions.

Python is used for data analysis and validation, PostgreSQL is used for structured SQL analysis, and Power BI is used to create an interactive business intelligence dashboard.

## Business Objectives

- Analyze overall revenue, cost, profit, and profit margin
- Identify profitable and low-margin product categories
- Analyze monthly sales and profitability trends
- Evaluate profitability across regions and sales channels
- Understand the impact of discounts on profitability
- Identify low-margin Region–Category–Channel combinations
- Compare category and subcategory performance
- Build an interactive Power BI dashboard for business insights

## Tech Stack

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Database:** PostgreSQL
- **Query Language:** SQL
- **Visualization & BI:** Power BI, Matplotlib, Seaborn
- **Development Tools:** VS Code, pgAdmin 4, Git, GitHub
